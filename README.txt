КАЛЬКУЛЯТОР АМПП — версия 1.0

Как запустить на компьютере:
1. Распакуйте архив.
2. В папке приложения запустите локальный сервер:
   python -m http.server 8000
3. Откройте в браузере: http://localhost:8000

Для телефона:
- приложение нужно разместить на любом HTTPS-хостинге;
- после открытия в браузере выберите «Добавить на экран Домой».

Логика:
- смена 6 часов использует тариф 6 часов;
- смены 7–12 часов используют тариф 8 часов;
- реальное рабочее время: 6→5,5; 7→6,5; 8→7,5; 9→8;
  10→8,75; 11→9,75; 12→10,75;
- стоимость смены = ЧТС × реальное время + тариф пика × операции;
- исполнителю 65%, КА 35%;
- производительность = операции / (реальное время × норма пиков в час).
